# Spinal IMU Host App

面向 C0、C4、C7 三节点 BNO055 系统的浏览器上位机。通过 Web Serial 接收 v1 二进制帧并兼容旧文本帧，分别显示三个 IMU 的姿态，并以分段插值驱动颈椎三维模型。

## 运行

要求桌面版 Chrome 或 Edge，以及 Node.js 18+：

```powershell
cd HostApp
npm install
npm start
```

浏览器打开 `http://127.0.0.1:4173`。点击“连接串口”后选择 USB 转串口设备，默认参数为 `115200 8N1`。没有硬件时可点击“运行模拟数据”检查界面和数据链。

## 工作窗口与数据曲线

顶部的三个标签切换工作窗口，采集链路和显示帧时间始终可见；切换不会断开串口、重启模拟源或清空历史。

- **姿态重建**：驾驶员模型、三个 IMU 独立姿态及模型下方的时间轴。
- **数据曲线 / IMU 数据**：C0、C4、C7 三幅曲线共用会话时间坐标，默认显示 Roll / Pitch / Yaw；可切换加速度 X/Y/Z、角速度 X/Y/Z。
- **数据曲线 / 相对角**：同图比较 C0–C4、C4–C7、C0–C7 的四元数最短旋转角，范围 0–180°；它不是有正负方向的单轴屈伸角。
- **采集诊断**：同步跨度、解析错误、接收字节及最近一行原始数据。

曲线可选择近 10/30/60 秒或全部缓存，点击图例显示/隐藏信号，悬停查看设备时间与数值，滚轮缩放时间范围、水平拖动平移，点击“复位范围”恢复所选时间范围。聚焦曲线后也可使用左右方向键逐帧选择，Home/End 跳到首/末帧。

点击曲线选中历史帧后，曲线读数、设备时间、IMU 数值与三维模型使用同一帧；切回姿态重建窗口即可查看对应模型。时间轴随当前窗口移动，只有一套回放状态。查看历史不停止接收；“返回实时”恢复最新帧。将显示中的姿态设为中立位时，缓存的姿态与相对角曲线会统一重新计算；加速度和角速度保持接收值。

数据与显示约定：

- 同步曲线和相对角使用最多 30,000 个完整三节点帧，同一序号下的 CSV 节点样本先组装再入缓存。只有单节点时，其独立三维卡片仍可工作，同步曲线等待完整帧。
- 横轴是从首帧开始累计的会话时间，优先使用设备时间间隔；二进制回绕扩展后用于显示，原始值保留在CSV。真正的设备计时回退采用上位机接收间隔，并断开该处曲线。该处理不代表硬件时钟同步。
- 二进制 v1：加速度 raw/100 → m/s²（含重力），角速度 raw/16 → °/s；旧 NDJSON/CSV 向量保留传输原始值。曲线单位随当前帧切换，不将不同单位的旧数据接成一条线。未传输或无效向量为“—”。
- 姿态角采用既有 Tait-Bryan 转换，与节点卡片保持一致。Roll/Yaw 跨越 ±180° 时断开曲线，避免误画尖峰；尚未映射到解剖学屈伸/侧弯/轴向旋转。
- 曲线采用保留极值的分箱绘制，绘图频率上限约 10 Hz；原始帧仍按接收速率进入缓存。未激活窗口停止图表与三维绘制。

前端模块边界：`timeline.js` 管理历史、会话时间与回放状态；`signals.js` 负责姿态、相对角与绘图采样数学；`curves.js` 负责曲线交互；`workspace.js` 负责标签窗口与单一时间轴的位置。新增信号时先扩展数据合同，避免在 UI 中补造测量值。

## 三维交互与历史回放

- 驾驶员主场景包含完整坐姿人体、座椅、方向盘、踏板和突出显示的脊柱。左键拖动旋转、滚轮缩放、右键拖动平移；三个 IMU 小视图支持同样操作。
- 人体由本地参数曲面生成，包含肩胸腰部轮廓、面部、手指和坐姿四肢。座椅默认淡化为透明参照，可通过“座椅透视”开关切换；“人体透视”用于观察内部脊柱。
- 每个视图左上角提供放大、缩小和复位按钮，触屏可使用单指旋转和双指缩放/平移。主视图另有全身、后侧观察和颈部聚焦三个预设。
- 时间轴直接嵌入颈椎姿态重建面板，缓存最近 `30,000` 个完整三节点姿态帧。点击时间戳、点击曲线或拖动游标，模型和三个节点读数会一起跳转。支持上一帧、下一帧及 0.5×/1×/2× 回放；“返回实时”恢复最新数据。
- 回放优先使用设备时间差，设备时间不可用时使用上位机接收间隔；设备零时刻有效。历史曲线覆盖整个保留区间，满缓存后滚动淘汰最早数据。
- 时间轴蓝线表示 C7 到 C0 的相对旋转角，橙线表示当前查看位置。串口采集在历史回放期间仍继续写入缓存。

运行解析与四元数测试：

```powershell
npm test
npm run test:ui
```

`npm test` 检查协议解析和四元数数学，`npm run test:ui` 使用本机 Microsoft Edge 检查 WebGL 渲染、视图操作及时间戳跳转。

浏览器回归测试使用内存串口输入已知的 0°/15°/30° 姿态，检查精确时间戳切换、模型联动、逐帧/倍速回放、座椅透视及手机布局。该验证不代表已经完成 STM32 实物串口联调。

曲线回归还检查三节点姿态与三组相对角的已知数值、曲线选帧与模型一致、窗口切换期间继续接收、中立位重算、缺失信号、图例开关、时间范围缩放及手机曲线布局。数学测试覆盖不等间隔采样、设备时间回退、短峰值保留和欧拉角环绕。

## 二进制协议与设备控制

v0.1.0.1 固件默认发送 A5 5A 开头的 v1 二进制帧。`wire.js` 在字节层分帧，校验长度/版本/CRC，再交给页面。
同口也可收到命令应答；损坏帧不更新姿态。断线后重新连接会重新识别协议。详见 [WIRE_PROTOCOL.md](../Docs/WIRE_PROTOCOL.md)。

“采集诊断”提供开始/停止上传、20/50/100 ms 轮询周期、IMU重新初始化、读取版本/就绪状态和保存校准。
请求有3 s应答超时，无自动重试。停止上传仍保持传感器维护；重新初始化的OK表示已接受，需等待节点再次有效。
保存校准先停止上传，且三颗各CALIB_STAT=0xFF；保存会使用Flash并短暂进入CONFIGMODE，不是人体中立位采集。
PC 使用外部3.3 V TTL USB-UART，原理图USB-C仅供电。两路串口都可控制同一系统。

二进制uint32时间回绕扩展为连续显示时间，原始值保留在timestampRawUs和CSV的timestamp_us中。无效帧不进入三节点模型历史，恢复后的曲线断开。
完整MCU健康快照未推送。序号跳变计数也包含停止上传间隙，不能当作纯链路丢包率。

## 兼容旧文本

NDJSON和CSV每行以 `\n` 结束，保留给旧设备与联调工具，不是当前固件的默认输出。例如三节点NDJSON：

```json
{"seq":42,"samples":[{"node":"C0","timestamp_us":842013,"q":[1,0,0,0],"accel":[0,9.81,0],"gyro":[0,0,0],"cal":3,"flags":1},{"node":"C4","timestamp_us":843102,"q":[1,0,0,0],"accel":[0,9.81,0],"gyro":[0,0,0],"cal":3,"flags":1},{"node":"C7","timestamp_us":844191,"q":[1,0,0,0],"accel":[0,9.81,0],"gyro":[0,0,0],"cal":3,"flags":1}]}
```

也支持每行一个节点的 CSV：

```text
IMU,seq,node,timestamp_us,qw,qx,qy,qz,cal,ax,ay,az,gx,gy,gz,flags
IMU,42,C0,842013,1,0,0,0,3,0,9.81,0,0,0,0,1
```

四元数顺序固定为 `[w,x,y,z]`，解析时会自动归一化。因此既可以发送浮点四元数，也可以发送 BNO055 的原始定点值。页面显示的 roll/pitch/yaw 使用 Tait-Bryan 角公式；正式实验前必须冻结传感器安装方向、BNO055 轴映射和解剖坐标系之间的转换关系。

## 真实性边界

- 三个独立 IMU 视图显示接收四元数经过可选中立位归零后的姿态。
- 人体、座椅和驾驶舱只是空间参照模型；脊柱模型在 C7→C4、C4→C0 两段做四元数球面插值，用于直观呈现区域运动。
- 胸腰段、手臂和下肢保持固定驾驶姿态；本地人体模型不是受试者三维扫描或医学影像模型。
- 三个表面安装节点不能恢复 C1–C7 每节椎体的真实运动，模型不是医学诊断或解剖重建结果。
- 当前顺序轮询是软件近似同步。页面的“节点同步跨度”只统计帧内时间戳跨度。

`wire.js` 负责二进制及分帧，`protocol.js` 保留旧文本解析。修改协议需同时更新 C/JS 和 tests/fixtures 中的互通向量。
